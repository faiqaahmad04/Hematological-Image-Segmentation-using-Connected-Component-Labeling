# WBC Segmentation using Digital Image Processing

A classical image processing pipeline for segmenting **white blood cells (WBCs), nuclei, and cytoplasm** from microscopy images.

### Techniques Used

* Gamma correction and Gaussian filtering
* Intensity-based thresholding
* 8-connectivity Connected Component Analysis (CCA)
* Dice coefficient for segmentation evaluation

### Tools

Python, OpenCV, NumPy

### Output

Generates separate masks for the WBC, nucleus, cytoplasm, and a combined segmentation mask.
